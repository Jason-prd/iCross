# iCross 前端页面说明

> 创建日期：2026-02-27

---

## 📋 已创建页面

### 1. 运营仪表盘 (DashboardNew)
路径: `/dashboard/new`

功能:
- 核心指标卡片（商品数、订单数、利润、利润率）
- 选品状态概览（已选品/待上架/已上架）
- 订单概览（待发货/处理中/已完成）
- 低库存预警列表
- 最近订单列表
- 代发订单概览

---

### 2. 选品管理 (SelectionProducts)
路径: `/products/selection`

显示字段:
| 字段 | 说明 |
|------|------|
| SPU | 商品SPU编号 |
| 商品名称 | 商品标题 |
| 选品状态 | 未选品/已选品 |
| 上架状态 | 未上架/待上架/上架中/已上架 |
| 采购价(¥) | 1688采购成本 |
| 供应商 | 代发商/仓库 |
| 类目 | 商品类目 |
| 操作 | 查看详情 |

统计卡片:
- 已选品总数
- 待上架数量
- 已上架数量
- 未上架数量

---

### 3. Ozon商品 (OzonProductsNew)
路径: `/products/ozon/new`

显示字段:
| 字段 | 说明 |
|------|------|
| SKU | 商品SKU |
| SPU | 主商品编号 |
| 商品名称 | 商品标题 |
| Ozon价格 | ₽售价 |
| 库存 | Ozon库存数 |
| 利润率 | 利润百分比 |
| 30天销量 | 月销量 |
| 状态 | 在售/下架/归档 |
| 最后同步 | 同步时间 |

统计卡片:
- Ozon商品总数
- 30天总销量
- 平均利润率
- 低库存预警数

---

### 4. 订单管理 (OrdersNew)
路径: `/orders/new`

显示字段:
| 字段 | 说明 |
|------|------|
| 订单号 | Ozon订单号 |
| 客户 | 买家名称 |
| 商品 | 商品信息 |
| 金额 | 订单金额 ₽ |
| 支付状态 | 已支付/待支付 |
| 配送状态 | 待发货/待收货/已送达/已取消 |
| 订单状态 | 待处理/处理中/已完成/已取消 |
| 下单时间 | 创建时间 |

统计卡片:
- 订单总数
- 待发货数
- 处理中数
- 销售额

---

### 5. 代发订单 (DropshipOrders)
路径: `/orders/dropship`

显示字段:
| 字段 | 说明 |
|------|------|
| Ozon订单号 | 平台订单 |
| SKU | 商品SKU |
| 数量 | 购买数量 |
| 销售价 | ₽ |
| 采购成本 | ¥ |
| 运费 | ¥ |
| 利润 | ¥ |
| 利润率 | % |
| 状态 | 待处理/处理中/已发货/已送达 |
| 物流单号 | 快递单号 |
| 下单时间 | 创建时间 |

统计卡片:
- 代发订单总数
- 待处理数
- 已发货数
- 总利润

详情包含订单流程时间线:
- Ozon下单
- 代发下单
- 已发货
- 已送达
